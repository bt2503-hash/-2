# ТехноДім — інтернет-магазин побутової техніки

Повноцінний сайт із сервером (Node.js) і базою даних (файл `data/db.json`).

## Запуск
1. Встановіть Node.js 18+ (https://nodejs.org).
2. У папці проєкту виконайте:
   ```
   npm install
   cp .env.example .env      (Windows: copy .env.example .env)
   npm start
   ```
3. Відкрийте http://localhost:3000

Без `npm install` сайт теж працює (потрібен лише для реальної відправки email).

## Адміністратор
Логін і пароль задаються у файлі `.env` (`ADMIN_EMAIL`, `ADMIN_PASSWORD`).
Якщо `.env` немає — `admin@tekhnodim.ua` / `admin123` (обов’язково змініть перед публікацією).
Адмін створюється при першому запуску; після цього змінити пароль можна, видаливши `data/db.json` або вказавши нові дані до першого запуску.

## Як працюють замовлення
1. Покупець реєструється (отримує 100 бонусів), додає товари в кошик, обирає доставку
   (Нова пошта / Укрпошта / самовивіз з магазину), місто, відділення, спосіб оплати,
   за бажанням списує бонуси.
2. Замовлення потрапляє в адмінку (вкладка «Замовлення») зі статусом «Нове»; адміну приходить сповіщення на email.
3. Адмін натискає «Прийняти» → покупцю автоматично надсилається чек на email,
   нараховується 5% бонусів. «Відхилити» повертає списані бонуси.
4. Далі адмін змінює статус: Відправлено → Виконано.

## Email
Налаштуйте SMTP у `.env` (приклад для Gmail: `SMTP_HOST=smtp.gmail.com`, `SMTP_PORT=465`,
`SMTP_USER` — ваша пошта, `SMTP_PASS` — «пароль додатка» Google) і виконайте `npm install`.
Якщо SMTP не налаштований, листи зберігаються у папці `outbox/` (зручно для демонстрації).
Оплата картою — лише вибір способу, платіжний шлюз не підключено.

## Структура
- `server.js` — сервер, API, авторизація, база, пошта
- `seed.json` — початкові 45 товарів у 3 категоріях
- `public/index.html`, `public/css/style.css`, `public/js/app.js` — сайт
- `data/db.json` — база (створюється автоматично), `public/uploads/` — фото товарів

## Можливості
Каталог із 3 категоріями (45 стартових товарів, кількість не обмежена), картки товарів, пошук за назвою/виробником/категорією,
фільтри за ціною та виробником, найдорожчий і найдешевший товар, кошик, бонуси, доставка й оплата,
обране, порівняння, замовлення, чеки, бонуси, панель адміністратора (замовлення; додавання, редагування, видалення товарів із фото).


## Оновлення інтерфейсу
- Перемикач світлої/темної теми збереженням вибору.
- Перемикач української/англійської мови для основних елементів інтерфейсу.
- Розширені фільтри в лівій панелі каталогу та сортування над товарами.
- Порівняння до чотирьох товарів за ціною, виробником, моделлю, гарантією та характеристиками.
- Адаптивна верстка для телефонів і планшетів.
- На першому запуску база даних створюється з `seed.json`; особисті локальні дані та `.env` не включені до архіву.


## Додані можливості (оновлення)
- Обране прив’язане до облікового запису та зберігається на сервері; можна додавати/видаляти товари з обраного.
- Особистий кабінет покупця доступний після входу: профіль, бонусний рахунок, історія й статуси замовлень, чеки, завершені замовлення та власні відгуки. Обране й порівняння також доступні окремими розділами.
- Відгуки з оцінкою 1–5 зберігаються в серверній базі; перед показом покупцям проходять модерацію адміністратором.
- На сторінці товару показуються опубліковані відгуки та середній рейтинг.
- У панелі «Адміністратор» є зведення за клієнтами, замовленнями, новими замовленнями, оборотом і відгуками; також доступний список клієнтів і модерація відгуків.
- Роль адміністратора відокремлена від покупця: кнопки покупки приховані, а сервер додатково блокує оформлення замовлення з адміністративного акаунта.
- Дані профілю, замовлень, товарів, обраного й відгуків зберігаються на сервері у `data/db.json`.
- Англійський режим розширено для каталогу, товарів, кошика, оформлення, обраного та панелі адміністратора; перекладаються також динамічно створені елементи й атрибути полів.

**Примітка щодо бази даних:** у цьому проєкті використовується серверне JSON-сховище `data/db.json`, а не MySQL/PostgreSQL. Воно створюється автоматично під час запуску. Для великого production-магазину варто перейти на PostgreSQL.

## Останнє оновлення
- Знято серверне обмеження на 10 товарів у категорії: адміністратор може додавати необмежену кількість позицій.
- Початковий каталог розширено з 30 до 45 товарів; нові позиції автоматично додаються до вже створеної бази без перезапису товарів, змінених адміністратором.
- Відновлено посилання на особистий кабінет покупця та маршрут `#cabinet`; після входу покупець може відкрити профіль, замовлення, бонуси й відгуки.
- Оновлено візуальний стиль карток, фільтрів, кнопок, таблиць, банера й адаптивної верстки.
- Англійський переклад поширено на більше елементів інтерфейсу, підказки полів і динамічний вміст.


## Відновлений доступ адміністратора та меню каталогу
- Стандартний доступ адміністратора після першого запуску без `.env`: `admin@tekhnodim.ua` / `admin123`. Змініть пароль перед запуском у відкритому доступі.
- Кнопка «Каталог» відкриває велике багатоколонкове меню з розділами та підкатегоріями; меню закривається повторним натисканням, кліком поза ним або клавішею Escape.
- Пошук із підкатегорії меню переводить до каталогу з відповідним пошуковим запитом.
